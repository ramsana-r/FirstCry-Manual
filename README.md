# FirstCry Website – Manual Testing Project

## Project Overview
Manual testing of the FirstCry e-commerce website to verify functionality, UI elements, navigation, and user interactions.

## Modules Tested
- Home Page
- Product Listing & Discovery
- Product Details
- Shortlist
- Cart Page

## Testing Activities
- Designed and executed test cases.
- Verified expected and actual results.
- Identified functional issues and documented failed test cases.
- Recorded Pass/Fail status.
- Prepared test documentation using Google Sheets.

## Test Environment
- Operating System: Windows
- Browser: Google Chrome

## Project Documentation
The PDF file in this repository contains the test cases and recorded results for the tested website modules.
